# WanderMap
A visual travel journal and blog website built with HTML, CSS, and JavaScript.

**WanderMap** is a visual travel journal and blog website designed to capture the emotions, memories, and experiences behind traveling.

Rather than functioning as a traditional travel guide, WanderMap focuses on presenting travel as a personal story through immersive visuals, destinations, journal entries, and interactive content.

## ✨ Features

* 🏠 Interactive landing page
* 📖 Travel journal
* 🗺️ Interactive travel map
* 🖼️ Travel gallery
* 🎥 Hero video section
* 📱 Responsive design
* 🎨 Warm and minimal visual design
* ⚡ Interactive elements using JavaScript

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Responsive Web Design

## 🎨 Design

WanderMap uses a warm, minimal visual style to create a relaxing travel-oriented experience.

The design focuses on:

* Warm beige tones
* Clean typography
* Large travel imagery
* Immersive layouts
* Simple navigation
* Storytelling through visual content
